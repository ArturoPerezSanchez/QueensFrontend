# QueensFrontend

A responsive React frontend for playing Queens puzzles generated by [QueensAPI](https://api.arturops.com/queens).

The app is designed to feel good on both desktop and phone screens: the board scales to the viewport, touch targets stay large, and the main game controls are always close to the puzzle.

## Features

- Playable LinkedIn-style Queens board
- Board sizes from `4 x 4` through `10 x 10`
- New puzzle and retry controls
- Timer with local best time per board size
- Conflict highlighting for rows, columns, regions, and adjacent queens
- Optional solution reveal
- Responsive layout for mobile, tablet, and desktop
- Same-origin API proxy setup for local development and Vercel deployment

## Game Rules

For a board of size `N`:

1. Place exactly `N` queens on the board.
2. Each row must contain exactly one queen.
3. Each column must contain exactly one queen.
4. Each colored region must contain exactly one queen.
5. Queens cannot touch each other, including diagonally.

These Queens pieces do not attack across full chess diagonals. Only neighboring cells matter for diagonal conflicts.

## API Integration

The frontend calls:

```text
/api/queens?board_size=<size>&solution=true
```

During local development, Vite proxies `/api/queens` to:

```text
https://api.arturops.com/queens
```

For Vercel deployments, `vercel.json` defines the same rewrite. This keeps browser requests same-origin and avoids CORS issues.

The API returns:

```ts
type QueensResponse = {
  board: number[][];
  solution: [number, number][] | null;
};
```

`board` contains region IDs. Cells with the same ID belong to the same colored region.

`solution` contains zero-indexed `[row, column]` queen positions when requested.

## Local Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

```text
src/
  App.tsx          Main application shell and game state
  api.ts           QueensAPI fetch client
  game.ts          Pure game-rule helpers
  types.ts         Shared TypeScript types
  main.tsx         React entry point
  styles.css       Responsive visual design
```

## Notes

Best times are stored in the browser with `localStorage`, scoped by board size.
